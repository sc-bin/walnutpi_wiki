The Walnut Pi system supports switching the operating system language via terminal commands, currently supporting Chinese and English. **The first switch takes a bit longer—about several tens of seconds. Please be patient.** The change takes effect after rebooting:

- Switch to Chinese:

```bash
sudo set-language cn
```

- Switch to English:

```bash
sudo set-language en
```
